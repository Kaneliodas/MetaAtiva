# **App Name**: MetaAtiva

## Core Features:

- Exercise Logging: Log exercises with details like type, duration, intensity, sets, reps and perceived effort (via emoji).
- Goal Progress: Visually track progress toward diverse goals (weight loss, running distance, etc.) with progress bars and celebratory badges upon completion.
- IMC Calculator: Calculate and display Body Mass Index (BMI), track BMI evolution over time with line graphs, and allow users to record and visualize body measurements.
- Training Plans: Offer pre-defined training plans for different fitness levels and goals. Allow users to create and customize their own plans, integrating with the exercise log.
- Social Sharing: Enable users to post completed workouts, achieved goals, and progress photos to a social feed. Implement follower, like, and comment features.
- Workout completion voice log: User says which exercise they did and MetaAtiva parses it using a tool to create entries into the app.

## Style Guidelines:

- Primary color: A vivid purple (#9400D3), associated with transformation, energy, and ambition.
- Background color: Dark purple background (#1E0036), very desaturated to put emphasis on interface elements.
- Accent color: A vibrant pink (#D30094), approximately 30 degrees 'left' of purple on the color wheel, for highlighting CTAs and progress bars.
- Body and headline font: 'PT Sans' (humanist sans-serif) for a balance of modernity and approachability.
- Use modern and clean icons to represent exercise types and achievements.
- Use a tile-based layout for clear, modular content display and easy navigation.
- Incorporate subtle animations to celebrate goal completion and provide positive feedback.
